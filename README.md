# KM 2 — English Preparation

Готовый статический сайт для подготовки к КМ 2. Не требует сервера, базы данных, платной подписки или API.

## Публикация на GitHub Pages

1. Создайте репозиторий на [GitHub](https://github.com/) (например, `km2-english-prep`).
2. Нажмите **Add file → Upload files**.
3. Загрузите **содержимое этой папки** в корень репозитория (не саму папку `km2_site`). Включите `index.html`, `style.css`, `data.js`, `app.js`, `manifest.json`, `sw.js`, `icon.svg`, `.nojekyll` и README.
4. Нажмите **Commit changes**.
5. Перейдите в **Settings → Pages**.
6. В **Build and deployment** выберите **Deploy from a branch**.
7. Выберите ветку `main`, папку `/(root)` и нажмите **Save**.
8. Дождитесь публикации. Ссылка появится вверху страницы Pages и будет примерно такой: `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.
9. Откройте ссылку, проверьте сайт и отправьте её участникам.

## Что реализовано

- 175 слов и выражений и 100 определений из предоставленных учебных документов.
- Вход по никнейму без пароля.
- Последовательное изучение с зачётами после каждых 10 карточек.
- Случайный марафон всех 275 карточек; для слов можно вписать перевод по-русски.
- Глоссарий с поиском и фильтрами.
- Отдельная работа над ошибками.
- Отдельная статистика точности по словам и определениям.
- Итог марафона с раздельными баллами по двум категориям.
- Подтверждение перед полным сбросом прогресса.
- Сохранение прогресса в браузере и офлайн-кеш при публикации по HTTPS.

## Важные ограничения

- Сайт не отправляет результаты владельцу и не имеет общей базы.
- Никнейм и прогресс сохраняются только в браузере/на устройстве участника. Между устройствами прогресс не синхронизируется; очистка данных браузера удаляет его.
- Ссылка не является паролем: любой, кто получил URL, может открыть страницу.
- Дедлайн 28 ноября 2026 года, 23:59 проверяется по локальным часам устройства. Это ограничение интерфейса, а не серверная защита.
- Для настоящей авторизации, общей статистики или серверного контроля доступа потребовалась бы серверная часть.
