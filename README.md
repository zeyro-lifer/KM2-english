# KM 2 - English Preparation · v2.1

Статический учебный сайт для подготовки к КМ 2. Не требует VPS, базы данных, платных сервисов или API.

## Публикация на GitHub Pages

1. Создайте репозиторий GitHub (например, `KM2-english`).
2. Загрузите **содержимое этой папки** в корень репозитория: `index.html`, `style.css`, `data.js`, `app.js`, `manifest.json`, `sw.js`, `icon.svg`, `.nojekyll`, README.
3. Нажмите **Commit changes**.
4. Откройте **Settings → Pages**.
5. В **Build and deployment** выберите **Deploy from a branch**, ветку `main`, папку `/(root)`, затем **Save**.
6. Дождитесь публикации и откройте ссылку GitHub Pages.

## Проверка письменных ответов

Письменный ответ сравнивается со строгим официальным переводом из документа. Учитываются только регистр, лишние пробелы, крайняя пунктуация и варианты `ё/е`. Если в исходном переводе указаны варианты через `/`, каждый из этих вариантов принимается. Синонимы, приблизительные совпадения и исправления по смыслу не засчитываются.

## Готовность к КМ 2

Показатель - доля карточек, на которые участник ответил правильно в последней попытке. Ошибочный ответ снимает карточку с отметки освоенных. Это учебный индикатор, а не прогноз оценки на контрольной.

Цвет шкалы: до 40% - красный; 41-80% - тёмно-оранжевый; 81-95% - жёлтый; выше 95% - зелёный.

## Локальные данные и приватность

- Никнейм, прогресс и ошибки хранятся только в `localStorage` браузера.
- Данные не отправляются владельцу сайта и не синхронизируются между устройствами.
- Очистка данных браузера может удалить прогресс. Резервного облачного хранилища нет.
- GitHub Pages не закрывает доступ по приглашениям: публичный репозиторий и сайт доступны всем, у кого есть ссылка (и потенциально могут быть найдены).
- Дедлайн 28 ноября 2026 года, 23:59 проверяется по локальным часам устройства. Это клиентское ограничение, его можно обойти изменением часов/кода.

## Офлайн-режим

Service Worker доступен только на HTTPS (GitHub Pages предоставляет HTTPS) или localhost. После первого успешного открытия сайта и загрузки файлов сайт может работать без сети. Обновления могут появиться после обновления страницы/перезапуска вкладки. Для проверки откройте сайт онлайн один раз, затем отключите сеть и перезагрузите страницу.
