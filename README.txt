KM 2 — ENGLISH PREPARATION
Готовый статический учебный сайт для публикации через GitHub Pages.

ЧТО ВНУТРИ
- 175 слов и выражений + 100 определений из исходных учебных документов.
- Вход по никнейму без пароля.
- Последовательное изучение и промежуточные зачёты каждые 10 заданий.
- Марафон всех 275 карточек в случайном порядке; письменный русский ответ для слов.
- Глоссарий с поиском и фильтрами.
- Работа над ошибками: неверно отвеченные карточки попадают в отдельный список и исчезают из него после правильного ответа.
- Раздельная статистика точности по словам и определениям.
- Итог марафона с общим результатом и отдельными результатами по словам и определениям.
- Подтверждение перед полным сбросом прогресса.
- Локальное сохранение прогресса и офлайн-кеш для опубликованной версии.

ПУБЛИКАЦИЯ ЧЕРЕЗ GITHUB PAGES (БЕСПЛАТНО)
1. Войди на https://github.com и создай новый репозиторий. Например, km2-english-prep.
2. Для простого запуска можно выбрать Public. Сам сайт не содержит секретных данных, но любой, у кого есть адрес, сможет открыть его.
3. Нажми Add file → Upload files и загрузи ВСЕ файлы и папки из этой директории в корень репозитория: index.html, style.css, data.js, app.js, manifest.json, sw.js, icon.svg, .nojekyll и README.txt.
4. Нажми Commit changes.
5. Открой Settings → Pages.
6. В Build and deployment выбери Deploy from a branch.
7. В Branch выбери main и папку /(root), затем Save.
8. Подожди завершения публикации (обычно несколько минут). Адрес будет вида https://ТВОЙ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/.
9. Отправь эту ссылку участникам. При первом открытии нужен интернет; после загрузки сайт сможет работать офлайн в поддерживаемом браузере.

ПРОВЕРКА ПЕРЕД РАССЫЛКОЙ
- Открой опубликованную ссылку на телефоне и компьютере.
- Проверь ввод никнейма, изучение, марафон, поиск в глоссарии и возврат на главную.
- Сделай тестовую ошибку и проверь раздел «Работа над ошибками».
- Убедись, что обновление страницы не стирает прогресс.

ВАЖНО О ДАННЫХ И ДОСТУПЕ
- Сайт не отправляет владельцу результаты участников и не использует общую базу данных.
- Никнейм и прогресс сохраняются в localStorage конкретного браузера/устройства. Между устройствами они не синхронизируются; очистка данных браузера удалит прогресс.
- Ссылка не является защитой паролем: любой человек, получивший URL, сможет открыть сайт. GitHub Pages не предоставляет скрытую авторизацию для такой статической страницы.
- Дедлайн 28 ноября 2026 года, 23:59 проверяется по локальным часам устройства посетителя. Это визуальное ограничение интерфейса, а не серверная блокировка: технически подкованный пользователь может его обойти.
- Для реальной авторизации, централизованного хранения или жёсткого ограничения по времени понадобится серверная часть.
- Сайт использует системный шрифт; интернет не нужен для его отображения. GitHub Pages раздаёт сайт по HTTPS, что позволяет service worker кэшировать файлы для повторного офлайн-доступа.

ЛОКАЛЬНЫЙ ЗАПУСК
Можно открыть index.html напрямую для быстрой проверки. Service worker и установка как приложение работают только на HTTPS (или localhost).
